Harker Diagram Plotter

Paste whole-rock major-oxide data (wt%) with SiO₂ as the first column — one row per sample. Each remaining oxide is plotted against SiO₂ as its own small panel, with a fitted trend line.

Data (CSV, header row required, SiO2 first)

Format: SiO2,MgO,CaO,Na2O,K2O,FeO,Al2O3 — one sample per line. Edit the example or paste your own.

Ready.
Runs client-side via PyScript (Pyodide). No server, no data leaves your browser.
